Сайт строительной компании ООО "СК КСМ"

О проекте

Данный проект — современный корпоративный сайт строительной компании, разработанный на Vue 3 + Vite.
Основная цель — представить услуги компании, портфолио реализованных объектов и обеспечить удобную обратную связь с клиентами.

Сайт сочетает в себе:
	•	современный дизайн с акцентами и яркими элементами,
	•	плавные анимации,
	•	адаптивность для любых устройств,
	•	SEO-оптимизацию для продвижения в поисковых системах.

⸻

🚀 Реализованные разделы и функционал

1. Главная страница
	•	Hero-блок с ярким заголовком и подзаголовком.
	•	Фоновая анимация с плавным появлением текста.
	•	Призыв к действию (CTA) с кнопкой для перехода к контактам/услугам.

2. О компании
	•	Подробная информация о компании и её ценностях.
	•	Анимации появления текста и изображений при скролле.
	•	Раздел, подчеркивающий надёжность и опыт (с фактами, цифрами).

3. Услуги
	•	Структурированный список услуг.
	•	Подробное описание каждой услуги.
	•	Выделение ключевых преимуществ (иконки, мини-блоки).
	•	Анимации карточек при наведении.

4. Галерея / Портфолио
	•	Галерея реализованных объектов.
    •	Все изображения приведены в современный формат (.webp).
    •	Все изображения сжаты без потери качества.
	•	Увеличение изображений при клике (lightbox).
	•	Сортировка и фильтрация по типам объектов.

5. Контакты
	•	Контактная информация: телефон, адрес, карта.
	•	Форма обратной связи с интеграцией через EmailJS.
	•	Проверка корректности данных в форме.
	•	Анимации при загрузке элементов.

⸻

🎨 Анимации и визуальные эффекты
	•	Плавные переходы между страницами (Vue Router + GSAP).
	•	Эффекты fade-in при прокрутке.
	•	Hover-анимации для кнопок и карточек услуг.
	•	Анимации появления изображений в галерее.

⸻

📱 Адаптивность
	•	Полная оптимизация под мобильные устройства и планшеты.
	•	Гибкая сетка и адаптивные изображения.
	•	Тестирование на разных разрешениях экрана.

⸻

🔍 SEO и аналитика
	•	Внедрён vite-ssg для статической генерации страниц (улучшенная SEO-оптимизация).
	•	Настроена структура мета-тегов и заголовков.
	•	Подключена аналитика Google Analytics и Яндекс.Метрика.

⸻

⚙️ Технологии проекта
	•	Vue 3 (Composition API)
	•	Vite (сборка и оптимизация)
	•	Vue Router (маршрутизация)
	•	EmailJS (отправка форм)
	•	GSAP (анимации)
	•	Bootstrap / кастомный CSS (стилизация и адаптивность)
